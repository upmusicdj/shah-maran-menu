# منوی دیجیتال قابل ویرایش شاه ماران

## چه چیزی آماده است؟
- پنل فارسی برای ویرایش نام برند، شعار، دسته‌بندی‌ها، نام آیتم‌ها و قیمت‌ها
- امکان افزودن/حذف دسته‌بندی و آیتم
- بارگذاری لوگو و تصویر جداگانه برای هر دسته
- پیش‌نمایش زنده و چاپ / ذخیره PDF
- خروجی و بازیابی پشتیبان JSON
- تولید QR برای آدرس عمومی منتشرشده

## اجرای فوری و رایگان
1. فایل ZIP را استخراج کنید.
2. فایل `index.html` را با Chrome یا Edge باز کنید. برای استفاده از پنل و پیش‌نمایش نیازی به نصب برنامه نیست.
3. متن‌ها و قیمت‌ها را اصلاح کنید، عکس‌های جداگانه بارگذاری کنید و «ذخیره تغییرات» را بزنید.
4. از «پشتیبان‌گیری» یک فایل JSON ذخیره کنید تا تغییرات قابل انتقال باشد.

## نکته مهم درباره QR و انتشار عمومی
QR فقط وقتی برای مشتریان کار می‌کند که سایت روی اینترنت منتشر شده باشد. فایل محلی یا آدرس `file://` برای مشتریان قابل دسترسی نیست.
- گزینه رایگان: GitHub Pages یا Netlify.
- برای GitHub Pages: یک مخزن بسازید، `index.html` را در ریشه و پوشه `assets` را آپلود کنید، در Settings > Pages انتشار را فعال کنید.
- پس از انتشار، URL عمومی سایت را در تب «QR Code و انتشار» وارد و QR را دانلود کنید.
- QR به آدرس عمومی به‌علاوه `?view=1` وصل می‌شود تا پنل مدیریت برای مشتری پنهان باشد.

## محدودیت نسخه فعلی
- این نسخه یک نمونه‌ی استاتیک و رایگان است؛ ذخیره تغییرات در مرورگر همان دستگاه انجام می‌شود، نه در یک حساب آنلاین مشترک.
- برای تغییر منو از چند گوشی/چند ادمین، به CMS یا پایگاه داده و ورود امن نیاز دارید.
- لوگو و عکس‌ها باید جداگانه بارگذاری شوند؛ تصویر اولیه منو تخت است و عناصر داخل آن به‌طور خودکار به لایه‌های مستقل تبدیل نمی‌شوند.
- کتابخانه QR از CDN بارگذاری می‌شود، بنابراین برای تولید QR اتصال اینترنت لازم است.
- قیمت‌ها و چند نام از روی عکس بازخوانی شده‌اند؛ قبل از انتشار نهایی بررسی شوند.
